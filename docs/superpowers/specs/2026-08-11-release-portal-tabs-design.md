# 发布中心 Tab 化设计说明

## 目标

将发布中心从纵向堆叠的功能区改为单行横向 Tab 门户。访问者一次只浏览一个主题，页面保留现有产品、技术演进、版本、下载与 FAQ 能力，同时统一为正式对外文案。

## 已确认方案

- 页面标题使用“产品发布中心”，说明为“集中呈现 SynlysAI 产品信息、技术进展、版本发布、官方资源与使用支持。”
- 一级 Tab 固定为“产品概览、技术演进、版本发布、资源下载、常见问题”。
- 采用门户式导航：Tab 横向单列排列，活动项使用底部品牌色指示和浅色背景，不使用卡片式分段控件。
- 默认打开“产品概览”；活动 Tab 写入 URL hash，支持直接访问与刷新恢复。
- 移动端保持单行，通过横向滚动容纳五项，不把 Tab 拆成多行或下拉菜单。

## 内容组织

- 产品概览：展示现有六产品入口与最新稳定版信息。
- 技术演进：展示“演进记录”筛选器和“技术演进记录”时间线，保留里程碑/全景演进切换。
- 版本发布：仅展示 Release 级别记录，标题为“版本发布记录”，不重复技术演进筛选器。
- 资源下载：展示“版本与资源”，保留产品、平台、架构筛选、校验和与同域下载。
- 常见问题：展示“常见问题”，保留搜索、分类、产品、版本范围及反馈。

## 交互与路由

活动 Tab 由 `/releases` 的 hash 决定：`#overview`、`#evolution`、`#releases`、`#downloads`、`#faq`。未知或空 hash 回退到 `overview`。产品卡的“查看下载”继续写入产品 query，同时切换到 `#downloads`。筛选 query 与活动 Tab hash 相互独立。

Tab 使用 `role="tablist"`、`role="tab"`、`aria-selected` 与 `aria-controls`。面板使用 `role="tabpanel"` 与稳定 ID。键盘焦点保持清晰；隐藏面板不进入读屏与 Tab 顺序。

## 视觉规则

导航与现有浅色官网视觉系统一致，使用直角趋向的小圆角、克制边框与品牌蓝活动指示。Tab 区域尺寸固定，切换内容不会改变导航高度。内容面板不套装饰性外层卡片，保持业务门户的信息密度。

## 验证标准

- 五项 Tab 桌面端单行显示，移动端单行横向滚动，无页面级横向溢出。
- 默认、hash 深链、产品下载跳转和技术演进 query 均恢复正确视图。
- 每次只渲染一个内容面板，原有筛选、时间线、下载和 FAQ 交互继续可用。
- 中英文页面标题、Tab 与各区域标题使用正式对外口径。
- 单元测试、构建与 Playwright 多视口截图通过。
