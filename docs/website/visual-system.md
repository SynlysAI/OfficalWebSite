# SynlysAI 官网视觉系统

## 视觉方向
- 极简、克制、企业级、偏硬科技
- 参考 OpenWebUI 的高密度信息展示方式
- 参考 `github-main` 的蓝紫渐变 logo 气质
- 以 AI4MS 现有蓝色系为主，紫色只做少量过渡

## Logo 使用
- 首屏使用 `SynlysAI` 文本主标题
- 辅助位置可用 `参考/AI4MS平台/github-main/.github-main/logo.png`
- logo 不做夸张发光，不做大面积变形
- 深色背景上优先用白底或浅底版本

## 颜色 token
- `bg`: `#07111f`
- `bg-soft`: `#0b1728`
- `panel`: `rgba(255,255,255,0.04)`
- `panel-strong`: `rgba(255,255,255,0.08)`
- `line`: `rgba(148,163,184,0.18)`
- `text`: `#e5eefc`
- `text-soft`: `#9fb1cd`
- `text-muted`: `#7b8daa`
- `primary`: `#4b8dff`
- `primary-2`: `#7b61ff`
- `teal`: `#2dd4bf`
- `warning`: `#f59e0b`

## 字体
- 中文正文：`PingFang SC` / `Microsoft YaHei`
- 英文与数字：`Inter`
- 等宽内容：`JetBrains Mono`

## 组件规则
- 卡片圆角控制在 `12px` 左右
- 主要按钮用实心蓝色
- 次级按钮用描边按钮
- 标签、状态、证据块用浅透明底色
- 页面不要堆太多浮层，不要用圆形装饰球

## 动效
- 只做轻量淡入、上移、hover 提亮
- 首屏允许一次性分层出现
- 不做夸张滚动视差，不做强噪点动画

## 图片策略
- 首选本地素材
- 优先用架构图、产品图、设备图、分析图
- 硬件图只作为执行端补充，不作为主叙事
- 禁止让单张图抢走首屏品牌位
