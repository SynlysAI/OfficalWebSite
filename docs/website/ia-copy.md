## 六层闭环文案
- `Research Spec`：把研发目标变成可执行规格
- `Skill`：把能力封装成可调用单元
- `MCP/SCP`：把指令和设备/服务连接起来
- `Memory`：把事实、日志、谱图和样品沉淀下来
- `Harness`：把执行边界、校验和审计建立起来
- `Self-correction`：把失败、异常和人工反馈纳入下一轮决策

## 核心模块文案
- AI4MS 门户：统一入口与品牌承接
- ResearchEngine：研发任务组织与闭环执行
- Spec Agent：多谱种解析与事实回写
- SpecLabOS：设备注册、工作流编排与运行状态回传
- SmartAccess：异构仪器软件的非侵入式接入
- Knowledge Base：证据检索、知识沉淀与回写
- Data Catalog：数据资产管理与追溯
- Report & Trace：报告生成、审计与复盘

## 场景叙事

`从研发目标进入，到实验动作编排、设备执行、谱图解析、结果回写，再到下一轮决策，SynlysAI 让企业研发流程形成可持续运行的闭环。`
